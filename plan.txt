내가 본 영화들을 기록하는 웹 사이트를 만드려고 해.

1. 리스트 화면
- 지금까지 등록한 영화 리스트를 보여주는 화면. 앨범 형식으로 한 페이지 당 한 줄에 5개씩 4줄로 20개 씩 리스트를 보여준다.
- 각 요소들을 클릭하면 모달로 해당 영화의 상세 정보가 뜬다.

2. 모달 화면 (리스트 클릭 시)
- 한줄평, 몰입감, 스토리, 감정, 좋았던 점, 아쉬웠던 점, 내 취향 여부, 별점 을 각각 한줄로 표시

3. 등록 화면
- 썸네일 업로드 할 수 있음.
- 한줄평, 몰입감, 스토리, 감정, 좋았던 점, 아쉬웠던 점, 내 취향 여부, 별점을 기록. 각 항목 세부 사항은 아래 4번에 기술.

4. 각 평가항목 세부정리
- 한줄평: 텍스트 입력가능. 최대 1000자 입력
- 몰입감: 좋음/보통/별로 총 세가지 항목으로 표시하고 클릭하면 선택되는 방식
- 스토리: 납득됨/그냥저냥/별로 총 세가지 항목으로 표시하고 클릭하면 선택되는 방식
- 감정: 웃김/긴장/슬픔/여운/없음 총 다섯가지 항목으로 표시하고 클릭하면 선택되는 방식
- 좋았던 점: 텍스트 입력가능. 최대 1000자 입력
- 아쉬웠던 점: 텍스트 입력가능. 최대 1000자 입력
- 내 취향 여부: 맞음/안맞음 총 두 가지 항목으로 표시하고 클릭하면 선택되는 방식
- 별점: 별모양 5개로 표시하고 클릭하면 클릭한 만큼 별점이 채워져야함. 별점은 5점 만점으로 별 반개도 가능(0.5점).
